# 🛍️ Ventas Click: Catálogo Directo a WhatsApp

Una solución sencilla y universal para negocios que necesitan un catálogo digital sin complicaciones. Permite configurar productos, moneda personalizada y recibir pedidos organizados por WhatsApp.

## ✨ Funciones principales
* **🌍 Multi-Moneda:** Configura el símbolo de tu moneda local ($, €, Q, etc.).
* **🛒 Carrito Dinámico:** Suma automática de productos y costo de envío.
* **📱 Pago Electrónico:** Botón para que el cliente copie tus datos de transferencia/pago con un clic.
* **🔗 Portabilidad Total:** Genera un link único que guarda toda tu configuración sin necesidad de bases de datos.

## 🚀 Prueba la App
👉 **[ACCEDER AL CATÁLOGO](https://josecruzcruz781-jpg.github.io/Ventas-Click-gratis/)**

## 🛠️ Configuración para Dueños
1. Abre la web y ve a la pestaña **"Mi Negocio"**.
2. Ingresa tus datos, WhatsApp y productos.
3. Dale a **"Guardar"** y luego a **"Generar Link para Clientes"**.
4. Comparte ese link generado; tus clientes verán tu catálogo listo para comprar.
